# historical-event-guessing-game-183366-183377

Backend (Flask) for Historical Event Trivia Game.

Quick Start
- Copy backend/backend.env.example to backend/.env and adjust if needed.
- Ensure the PostgreSQL database from the database container is running (see database README).
- Run the app:
  cd backend
  python run.py

- See backend/INTEGRATION.md for full multi-container setup, CORS/cookie details, and verification steps.
